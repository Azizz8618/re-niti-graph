# re-niti-graph

Дизассемблированная системная библиотека 22 БЭСМ-6 (ГРАФОР-СУД).

Материал перенесён из проекта [re-siprod](https://github.com/Azizz8618/re-siprod),
где хранился в `notes/grafor22-disasm/`.

## Состав

- `disasm/` - листинги дизассемблера по зонам (`zone_*.txt`), индекс `INDEX.md`, сводка `GRAFOR-GREP.txt`.
- `extract/` - извлечённые биты зон (`bin/`), каталог модулей, скрипты извлечения и `README.md` с описанием метода.
- `functions/` - описания функций ГРАФОР (по алфавиту, `FUNCTIONS*.md`).
- `madlen/` - исходники и объекты МАДЛЕН, каталог команд, АУДИТ.

## Источник

Образ диска БЭСМ-6 `/usr/local/share/besm6/2048`, зоны `0o1100..0o1177`.
Каталог: `*LIBRARY:22 /ГРАФОР-СУД/ 1201 10.12.91`.

Подробности формата, верификации и оговорок смотрите в
[`extract/README.md`](extract/README.md) и [`disasm/INDEX.md`](disasm/INDEX.md).
