| f06-sawtooth | `M 97 0 133 0 133 500`, `M 903 500 903 0` | 24 резких излома между Y=0 и Y=500 |

Координаты SVG инвертированы по Y: `Y_svg = maxY - y`. Например у f01
внешняя вершина с БЭСМ-координатой `(500,100)` изображается внизу
(`Y_svg = 824 - 100 = 724`), а внутренняя `(500,660)` — выше. Это
ожидаемое следствие инверсии, а не перепутанные вершины.

## Воспроизводимость

Каждая дека прогонялась дважды в отдельных каталогах с копиями бинарника и
дисков. Для всех шести дек три файла (`plot.dat`, `benson.out`, `benson.svg`)
побайтно совпали (cmp в раунде 1 против раунда 2), то есть хэши
детерминированы на этой связке «бинарник dispak + образ 2348-niti.img +
побайтное содержимое деки». Повторный полный прогон (рабочий каталог
`/var/tmp/plotter-figures.6FXykZ`) дал те же три SHA для каждой деки и тот же
итог 6 PASS, 0 FAIL. Изменение любой из трёх величин меняет хэши; это не
регрессия без проверки геометрии.

## Оговорки

- Коды `65xx` в `benson.out` — `[аналог NASA, БЕНСОН-501]`, то есть аналог
  NASA TM-76182 для БЕНСОН-501, а не подлинный протокол НИТИ/БЭСМ-6.
  В фактическом файле коды 4-значные; раннер допускает и форму `065xx`.
- SVG — растр в шагах 0.1 мм, а не «идеальная» геометрия: Manhattan, путь
  из `(0,0)`, квантование `INT`, инверсия Y, схлопывание коллинеарных точек.
  Подробности в `EXPECTED.md`.
- Раннер не трогает репозиторий: весь вывод идёт в `TMPDIR`, а без
  `KEEP_WORK` рабочий каталог удаляется через `trap`. Git commit и push не
  выполнялись; `.bak` не создавались.
