## Системные/дисковые модули (значимые для OVERLAY*)

Эти модули образуют низкоуровневый слой каталог/зона/диск библиотеки 22. Связь с `OVERLAY*` — **функциональное совпадение ([I])**: прямого решенного ребра вызова между работником `OVERLAY*` (зона 0o1457 тома 2048) и этими модулями в корпусе нет; для доказательства нужно расшифровать таблицу внешних символов DMS `OVERLAY*`.

| Модуль | Назначение (по MADLEN) | Связи |
|---|---|---|
| `E70` | обёртка входа: `13,VJM,*70` | точка входа в обработчик Э70 |
| `*70` (`_s70.mad`) | собственный обработчик экстракода 070: `*50,1206B/115B/116B`, `*72`; 51 команда, 5 констант | вызывается через `E70` |
| `GDISC` | работа с диском/зоной через `*50`; 16 команд | вызывается `SETK`, `GIVZON`, `NEXTZN` |
| `FDISC` | закрытие/освобождение диска (reference-запись, тело вCATALOG не найдено) | в цепочке `GDISC → … → FDISC` |
| `RCATAL` | чтение каталога; передаёт управление через `UJ` встроенным `RZONE`/`WZONE` | `SETK`, `GIVZON` |
| `WCATWO` | запись двух слов/каталожной пары | цепочка `SETEND → WCATAL` |
| `WCATAL` | запись каталога (reference-запись) | завершение цепочки |
| `RZON` / `RZONE` | чтение зоны; `RZON` передаёт управление в `E70`/`*70` | `RCATAL` |
| `WZON` / `WZONE` | запись зоны | `RZONE`/`CLEAZN` |
| `CLEAZN` | заполнение буфера `76001B` циклом `VLM`, запись через `STX` | зачистка зоны |
| `COMPDT` | сравнение двухсловного упакованного поля `DATA*` (ASN/APX/AOX, LOG-маски) | служебная |
| `COPDCB` | копирование смещений +0/+1/+3/+4 между областями (M9/M10), маска `7777177777777777` | служебная |
| `SETIND` / `SETREF` | установка индекса/ссылки в каталоге | `GIVZON` → `SETREF` |
| `SETZON` / `SETWGR` / `SETEND` | установка зоны, слова, признака конца | `SETK`, `SETEND` в цепочке каталога |
| `SETK` | диспетчер цепочки `GDISC → RCATAL → SETEND → WCATAL → FDISC` | главный системный модуль |
| `GIVZON` | выдача зоны: `GDISC → RCATAL → GIVENZ → SETREF → WCATAL → FDISC` | главный системный модуль |
| `NEXTZN` | обход зон, обрамлённый `VJM GDISC` / `VJM FDISC` | системный |
| `GIVENZ` | выдача записи/номера зоны | `GIVZON` |
| `FCATBD` | каталогный буфер (1 команда) | системный |
| `FOPEN` | открытие файла/библиотеки | файловый слой |

Полные цепочки вызовов и детали на уровне регистров — в `FUNCTIONS-E-H.md`, `FUNCTIONS-N-R.md`, `FUNCTIONS-S-Z.md`.

## Графические подсистемы (кратко)

- **Геометрия/кривые:** `ARC*`, `AREB*`, `CIRC*`, `CIRT*`, `ELIPS`, `ELLPS`, `SPLINE`/`SPLINT`, `TRIDIG`, `CUBPOL`, `APPOLY`, `POLINE`, `POLREG`, `SPIRAL`, `STAR`, `PATCH`.
- **Оси/линии/подписи:** `AXES`, `XAXIS`, `YAXIS`, `THAXES`, `RAXES`, `LINEO`, `LINEMO`, `LINEMC`, `LINEC`, `MARKER`, `NUMBER`, `NUMLIN`, `LINNUM`, `SIZLIN`, `SIZNUM`, `LGLINE`, `XLGAX`, `YLGAX`, `TMLGF`, `SHEAR`, `ROTATE`, `ATRAN2`.
- **3D/скрытые линии:** `HC*` (`HCIND`, `HCINV`, `HCLINE`, `HCMULT`, `HCNCRD`, `HCPRSP`, `HCROT1`, `HCSURF`, `HCUNIT`), `THREED`, `TD*` (`TDROT`, `TDSCAL`, `TDSECT`, `TDTRAN`, `TDLINE`, `TDLIM*`), `AXONOM`, `ISOMET`, `DIMET`, `CABIN`, `VIEW`, `SAVETR`, `SETTR`, `SETTR`.
- **Аппроксимация/численные методы:** `LSFIT`, `FORFIT`, `FORIF`, `FORIT`, `LESQ`, `SMINV`, `FNROOT`, `SECFNT`, `SECANT`, `DERIV5`, `SINCL`, `TCALC`, `MINMAX`, `MNMX`, `LIMITS`, `TDLIM`.
- **Структуры графических элементов:** семейства `RD*` (чтение элементов) и `WR*` (запись элементов) над общим блоком `*GFGEL*` (LC,28); `STRMOD`, `GFFALS` (8 русских сообщений об ошибках), `BUFL`, `MDBUFF`.
- **Служебные/диагностика:** `BEGLEV` («СЛИШКОМ МНОГО СКОБОК В АФФИНЫХ ПРЕОБРАЗОВАНИЯ X»), `ENDLEV` («НЕВЕРНОЕ ЧИСЛО СКОБОК»), `AXISC` (12 сокращений месяцев), `COPDCB`, `COMPDT`, `CLEAZN`.

Все описания, включая код/ CONST-значения и номера строк `.mad`, — в шести файлах выше. Неопределённые реконструкции помечены `[I]`; подтверждённые факты (рёбра вызовов, имена общих блоков, строки, экстракоды, размеры) — без метки.
