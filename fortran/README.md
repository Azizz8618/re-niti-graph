# Порт библиотеки 22 (ГРАФОР-СУД) на Фортран для ФОРЭКС 4.12

Этот каталог содержит перенос 238 подпрограмм библиотеки 22 с автокода
МАДЛЕН на Фортран. Исходный материал: `../madlen/*.mad` (дизассемблирование
`dtran` DMS-модулей с тома 2048).Semantic‑описания: `../functions/FUNCTIONS*.md`.

## Целевой компилятор

Рабочий компилятор — **ФОРЭКС 4.12 от 25.06.85**, доступный в C-симуляторе
`dispak` по команде `*TRANS:FOREX3*,,411550` (диск 41 = `2148`, зона `0o1550`).
Эталонный прогон: `/home/azizz/Yandex.Disk/re-forex/tests/plan-f77/t412/run-4.12.sh`.

Диалект: Фортран‑77 в фиксированной форме (`C` в первом столбце, код в 7-72).
Ограничения, подтверждённые для этого семейства компиляторов:

- имена — **не более 6 символов** (буквы A-Z, цифры 0-9, первая — буква);
- рабочие конструкции: `PROGRAM`, `SUBROUTINE`, `FUNCTION`, `ENTRY`,
  `COMMON`, `BLOCK DATA`, `DATA`, `EQUIVALENCE`, `PARAMETER`, `EXTERNAL`,
  `DO ... CONTINUE`, блок `IF`, `GOTO`, `LOGICAL`, `INTEGER`, `REAL`,
  `DOUBLE PRECISION`, массивы, `**`, `PRINT n`, `WRITE(54)`, `FORMAT`;
- **не использовать**: `IMPLICIT NONE`, `SAVE`, `PRINT *`, `END DO`,
  `DO WHILE`, `CHARACTER`, `END=`, `INCLUDE`, `LOWER CASE`;
- на живом FOREX 4.12 дополнительно подтверждено: фиктивные массивы
  `A(*)` не принимаются — использовать фиксированную длину `(1000)`;
  `ENTRY` с объявлениями после него и с массивами-параметрами отклоняются,
  поэтому псевдо-ENTRY, появившиеся из MADLEN `SUBP`, удалены централизованно;
- прямые вызовы экстракодов из Фортрана неподтверждены — вместо них
  вызываются обёртки из `SUPPORT.FTN`.

## Именование

- Имя файла: `<имя_модуля>.FTN`, где имя модуля приведено к 6 символам
  (например `MOVE1`, `ITPLBV`, `_s70` -> `S70`, `FT*571` -> `FT571`).
- Имя подпрограммы: то же, что и файл.
- **Важное уточнение:** MADLEN `LABEL :,SUBP,` — это объявление **внешней**
  подпрограммы (вызов через `VJM`), а не точка входа текущего модуля.
  Поэтому такие символы переводятся в `EXTERNAL <имя>` / `CALL <имя>`,
  а не в `ENTRY`. `ENTRY` применяется только когда тело символа реально
  находится в этом же DMS-модуле (например `RZONE`/`WZONE` в `RCATAL`,
  `WZON` в `WCATWO`). Это подтверждено батчами 1, 3, 4.
- Общие блоки `,LC,n` превращаются в `COMMON /<ИМЯ>/ <ИМЯ>(n)` в `COMMON.FTN`.
  Имя блока — имя LC-символа без звёздочек, усечённое до 6 символов.

## Соответствие MADLEN -> Фортран

| MADLEN | Фортран |
|---|---|
| `,NAME,` | `SUBROUTINE <ИМЯ>` |
| `...,SUBP,` | `EXTERNAL <ИМЯ>` + `CALL <ИМЯ>` (внешняя ссылка); `ENTRY` — только для тел внутри модуля |
| `,LC,n` / `,BSS,n` | `COMMON /X/ X(n)` / локальный массив |
| `,EQU,` | `EQUIVALENCE` или `PARAMETER` |
| `,LOG,n` / `,INT,n` / `,ISO,` / `,TEXT,` | `DATA` с десятичным/символьным значением |
| `ATX` / `XTA` | присваивание (`A = X` / `X = A`) |
| `A+X`, `A-X`, `A*X`, `A/X` | арифметика |
| `AAX`, `AOX`, `AEX`, `ARX` | `AND`, `OR`, `XOR` (через `IAND/IOR/IEOR`) |
| `ASN`, `APX`, `AUX` | сдвиг/упаковка битов (подпрограммы в `SUPPORT.FTN`) |
| `VTM`, `WTC`, `UTC`, `NTR` | локальные `INTEGER` индексы/модификаторы |
| `VJM`, `UJ` | `CALL` / `GOTO` |
| `UZA`, `U1A`, `VZM`, `VIM` | `IF (A .EQ. 0) ...` / `IF (M .NE. 0) ...` |
| `VLM` | `DO ... CONTINUE` |
| `*50`, `*70`, `*72`, `*74` | `CALL EXC50/EXC70/EXC72/EXC74` из `SUPPORT.FTN` |
| `PLOT`, `PEN`, `ONOFF`, `FRAME`, ... | `CALL PLOT/...` — внешние точки входа физического уровня |

## Физический уровень графопостроителя

В библиотеке 22 нет собственного кода привода пера: модули `MOVE1/2/3`,
`STRMOD`, `MOVA`, `DASHP` и др. вычисляют координаты и передают их внешним
точкам входа из вторичного каталога зоны `0o1163`: `PLOT`, `PEN`, `ONOFF`,
`FRAME`, `FRAGM`, `EFRAGM`, `GROPEN`, `GRWRIT`, `GRCLOS`, `GRNOTZ`,
`GRNAME`, `WRITC`, `ENDPG`, `PAGE`, `SET`, `IDENT`, `ITALIC`.
В порте они объявляются как `EXTERNAL` и реализованы заглушками в
`PLOTSTUB.FTN` (протоколируемыми вызовами), чтобы программу можно было
прогонять на FOREX 4.12 без реального графопостроителя.

Низкоуровневый обмен с диском (`GDISC`, `RCATAL`, `E70`, `*70`, `FOPEN`)
использует экстракоды `*50`/`*70`/`*72`; в порте они заменены вызовами
обёрок `SUPPORT.FTN`, которые на БЭСМ-6 соответствуют системным вызовам
ДИСПАК (Э50 — формирование задачи, Э70 — обмен с внешней памятью).

## Правила портирования

1. Читать `../madlen/<MODULE>.mad` и описание модуля в `../functions/FUNCTIONS*.md`.
2. Сохранить **внешний интерфейс**: имя подпрограммы, все `ENTRY`, набор
   COMMON-блоков и порядок слов в них.
3. Сохранить **семантику** (что делает модуль), а не побайтовую последовательность
   команд. Неточные места помечать комментарием `C [I] ...`.
4. Не выдумывать назначение модуля: если описание в FUNCTIONS.md отсутствует,
   написать `C [I] semantics unclear` и перевести только однозначные части.
5. Не изменять `COMMON.FTN`, `SUPPORT.FTN`, `PLOTSTUB.FTN` — они общие.
6. Один файл на модуль. Не создавать параллельных копий и `.bak`-файлов.
7. Комментарии только на русском или английском, без выдуманной истории.
