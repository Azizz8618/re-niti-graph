# Первичные источники: интерфейс «БЕНСОН»

## NASA TM-76182

- Файлы: `NASA-TM-76182.pdf` (17 страниц), `NASA-TM-76182.txt` (полное распознавание текста, с маркерами `PAGE N of 17`).
- Origin: NASA Technical Memorandum 76182, сентябрь 1980. Заголовок:
  «Linking of the "BENSON" Graph-Plotter with the "ELEKTRONIKA-100I" Computer».
  Авторы: I. Ye. Val'tts, N. Ya. Nikolaev, M. V. Popov, V. A. Soglasnov.
- Перевод отчёта Института космических исследований АН СССР, Москва,
  Report Pr-448, 1978, стр. 1-17: «Сопряжение графопостроителя "БЕНСОН"
  с ЭВМ "Электроника-1001"».
- Источник: NASA Technical Reports Server, NTRS ID `19810010147`.
  PDF: `https://ntrs.nasa.gov/api/citations/19810010147/downloads/19810010147.pdf`.
- SHA256 PDF: `2f846e5e9a507ec8508f2d46d5073e9a...` (полный в `sha256sum`).
- Распознавание: текстовый слой PDF извлечён `pymupdf`, страницы 15-17
  (рисунки) дополнительно пропущены через `tesseract` при 300 dpi.
  Текст сохранил огрехи микрофильмирования, при цитировании сверять с PDF.

### Что даёт отчёт для темы ГРАФОР/НИТИ

- Модель: «БЕНСОН-FRANCE» модель 501, шаговые двигатели, перо с подъёмом/опусканием.
- шесть линий управления: `+X`, `-X`, `+Y`, `-Y`, `Pen Control` (перо вверх/вниз),
  импульс +5 В на соответствующей шине; блокировка `Pen Control` на корпус =
  опущенное перо. Разъём 11 на боковой стенке.
- Интерфейс включается в стандартную систему команд ВВ Электроники-1001:
  первые три значащих бита 12-разрядного слова = код операции (для ГП выбраны
  коды `50` и `51`), следующие три = номер устройства, последние три =
  специальные импульсы УВИ (VV1/VV2/VV3). Итого шесть команд.
- Таблица 2 (стр. 6-7 PDF) перечисляет команды, но распознана плохо;
  сверять по изображению.
- Программная часть: установка начала координат и масштабов по X/Y, вывод
  символов по их элементным кодам, кольцевой буфер, покадровая выдача.

Это не советский протокол НИТИ напрямую, а современный ему аналог на
Электронике-1001. Использован как OSINT-подтверждение физической модели
«Бенсона» и шесть управляющих линий.
