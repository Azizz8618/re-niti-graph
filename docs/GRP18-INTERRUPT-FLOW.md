# Линия 18-го разряда ГРП: полный путь прерывания от БЕНСОНА

Документ собирает в одном месте весь путь 18-го разряда ГРП в реальной ОС
ДИСПАК: вход через `disp70.be`, подмена вектора в `dudka.be`, обработчик
`ВХОД`, аварийные ветви и возврат в диспетчер. Отдельно показано, что делает
наш стенд на базе `dispak` и чего он не делает. Все номера строк даны по
рабочим копиям на 2026-11-22: `/home/azizz/Yandex.Disk/re-dispak/` для `.be`
и `.lst`, `/home/azizz/Yandex.Disk/dispak/` для C-кода (HEAD `87f317b`).
Пути в ссылках указаны от каталогов `/home/azizz/Yandex.Disk/`.

Главная коррекция прежнего описания: 18-й разряд это **внутреннее**
прерывание. Оно идёт через `ВНУПР`, а не через `ОБВНПР`. Повторное чтение
ГРП, маска `МГРП`, приоритет `каска` и гашение выбранного разряда через
`сч E48-1(М16); нтж ЕДК10Р` относятся к внешнему пути (`ОБВНПР`,
`disp70.be:1431-1451`), а не к 18Р.

## 1. Две точки входа в ДИСП70

`disp70.be:222-225` задаёт аппаратные точки входа:

```
START   зп  СМ          , ВХОД ПО АДРЕСУ 500 – ВНУТРЕННЕЕ ПРЕРЫВ.
        пб  внупр       , ПЕРЕХОД НА ОБРАБОТЧИК ВНУТРЕННИХ ПР.
внешпр  зп  СМ          , ВХОД ПО АДРЕСУ 501 – ВНЕШНЕЕ ПРЕРЫВ.
        пб  ОБВНПР      , ПЕРЕХОД НА ОБРАБОТЧИК ВНЕШНИХ ПР.
```

Шапка обработчика внутренних прерываний (`disp70.be:976-981`) прямо
указывает вход по адресу `500₈`. Значит 18Р, который ДУДКА разрешает через
`сч E18; пв ТВ67(М15)` (`dudka.be:163-165`), обрабатывается в `ВНУПР`.

### 1.1. Что делает `ВНУПР` (`disp70.be:982-1008`)

| Строки | Команды | Смысл |
|---|---|---|
| `:982-993` | `счрж '77'; зп РК`, `счи М17; зп И17`, `счмр 64; зп РМР`, `счи М16; зп И16`, `счи М15; зп И15`, `счи М20; зп И20` | Сохранение РК, И17 (указатель магазина), РМР, И16, И15 (адрес возврата), И20 |
| `:994-995` | `рег '237'; зп РЭ4` | Чтение главного регистра прерываний (ГРП) на сумматор, сохранение в РЭ4 |
| `:996-999` | `и ПОДПРГ; зп РЭ2` | Выделение только внутренних разрядов; комментарий называет разряды 23-20 и 15-13 |
| `:1000-1002` | `сч ГАШРП1; уи; рег '37'` | Гашение обработанных разрядов ГРП по маске `ГАШРП1` |
| `:1003-1005` | `сч РЭ2; по БМВ` | Если внутренних флагов нет, ложное прерывание, возврат к основному циклу |
| `:1006-1008` | `нед; уи М16; пб обвнп1-1(М16)` | Выбор старшего установленного разряда, номер в M16, переход по таблице обработчиков |

`рег '237'` читает ГРП на сумматор. Доказательство шаблона: следующая за
`рег '237'` команда в `disp70.be:1431-1439` работает с аккумулятором
(`и шкпре1`, `или ШКПРЕ`, `и ГАШРП1`, `и МГРП`). Та же пара `рег '240'` и
`сбр ЧЕРЕЗ1` в `dudka.be:265-266` читает слово Бенсона именно на сумматор.

### 1.2. Чем внешний путь отличается

Внешний обработчик (`disp70.be:1431-1451`) после `БМВ` делает повторное
`рег '237'`, `или ШКПРЕ`, `и ГАШРП1`, `и МГРП`, `зп РЭ1`, проверяет `каска`,
а затем в точке `куку` (`1444-1450`) выполняет `нед; уи М16;
сч E48-1(М16); нтж ЕДК10Р; уи; рег '37'; пб обвнп1-1(М16)`. Это другая
ветвь, для разрядов 48-25. Отождествлять её с прохождением 18Р неверно:
в `ВНУПР` повторного чтения ГРП, `МГРП` и `каска` нет.

Обе ветви оканчиваются переходом `пб обвнп1-1(М16)` в общую таблицу
`ОБВНП1`, поэтому сам адрес `обвнп1+30` используется и внешним, и внутренним
путём. Различается только процедура, которая этот адрес выбирает.

## 2. Формула вектора 18Р

В таблице `ОБВНП1` (`disp70.lst:1532-1535`) база равна `03765₈`:

```
1535: 03765 00 23 02124  ...  ОБВНП1 МОД   ТУС+1
```

Обе диспетчеризации-ветви переходят по `пб обвнп1-1(М16)` (`disp70.be:1008` и
`:1450`). Команда `нед; уи М16` выдаёт номер установленного разряда в
1-базовой нумерации, поэтому:

```
M16 = 49 - r
адрес = обвнп1 - 1 + M16 = обвнп1 + (48 - r)
```

Для r = 18 получается `M16 = 31`, смещение `48 - 18 = 30` (десятичное,
то есть `36₈`) и адрес `03765₈ + 36₈ = 04023₈`.

Вектор 18Р в листинге (`disp70.lst:1610`, метка строки 1655):

```
1610: 04023 00 033 4100  ...  УВВ   ’4100’
1611: _04023                  * ОПРОС ТЕЛЕГРАФНЫХ КАНАЛОВ СВЯЗИ
1612: + 0064 00 30 0000  ...  ПБ    VТ19
```

ДУДКА подменяет именно эту ячейку: `сч обвнп1+30` (`dudka.be:121`).
Разница адресов `04023₈ - 03765₈` равна `36₈`, то есть 30 в десятичной записи. Это совпадает со смещением из формулы.

Комментарий `dudka.be:121` называет `обвнп1+30` «вектором 31-го разряда
ГРП». Это ошибка: число 31 это значение `M16 = 49 - 18`, индекс в команде
`пб обвнп1-1(М16)`, а не номер разряда ГРП. Сам разряд остаётся 18-м, что
подтверждено разрешением маски `сч E18; пв ТВ67(М15)` (`dudka.be:163-165`)
и снятием `сч E18; пв ТВ67А(М15)` (`:201-203`).

## 4. Обработчик `ВХОД` (`dudka.be:249-294`)

### 4.1. Управляющая последовательность

Первые две команды восстанавливают базу: `мод БНСО; уиа 0(М16)`
(`:251-252`). Далее в `РЕГ '34'` идут **шесть** записей, а не пять:

| N | Строки | Подготовка слова |
|---:|---|---|
| 1 | `:253-254` | `сч` (нуль), `рег '34'` |
| 2 | `:255-256` | `сч D10167`, `рег '34'` |
| 3 | `:257-258` | `сч` (нуль), `рег '34'` |
| 4 | `:259-260` | `сч е28е25`, `рег '34'` |
| 5 | `:261-262` | `сч` (нуль), `рег '34'` |
| 6 | `:263-264` | `сч D10171`, `рег '34'` |

`D10167 = в'0000001500000040'` (`:320`) и `D10171 =
в'0000001140000000'` (`:322`) по комментарию `:324-341` помечены как
«ПРЕДПОЛОЖИТЕЛЬНОЕ ЗНАЧЕНИЕ»; по `rukava.be:404,536` `РЕГ '34'` это запись
маски ПРП, а не команда устройству.

Следующая за шестой записью команда `рег '240'` (`:265`) читает очередное
слово от Бенсона. Слово оказывается на сумматоре: сразу после чтения идёт
`сбр ЧЕРЕЗ1` (`:266`), работающий с аккумулятором. Маска
`ЧЕРЕЗ1 = в'5252525252525252'` объявлена в `:308`.


Страница содержит 1024 слова (`уиа -1023(М15)`, `:134-137`), но из-за
чередования фаз `D10156` на одну страницу приходится около 2048
прерываний: в одной фазе слово записывается, в другой обработчик только
переключает фазу и уходит в `БМВ1`.

## 6. Возврат в диспетчер

Цепочка возврата (`disp70.be`):

```
пб БПУ                 :1820-1848  блокировка внешних ПР, упрятывание контекста
  -> БВЗ               :1849       блок переключения задачи
  -> БВЗ32             :2059-2099  выгрузка/восстановление контекста
  -> БМВ1 / КИК1       :2105-2125  продолжение выполнения
  -> выпр (М3)         :2125       выход из прерывания
```

`БВЗ32` восстанавливает `M17` командой `зпм И17` в `disp70.be:2089`.
`КИК1` (`:2114-2125`) восстанавливает `M16`, `M15`, `M20`, `РМР`, `СМ`
и `РК`, но **не восстанавливает `M17`**. Это асимметрия двух путей возврата:
через `БВЗ32` регистр восстанавливается, через `КИК1` нет.

Отметка `E37` в `ШГ` (`dudka.be:287-289`) это шкала готовности задачи.
Она не поднимает 18-й разряд ГРП и не является аппаратным прерыванием.
Реальные действия по пробуждению задачи делает `пб БПУ` уже после того,
как обработчик завершился.

| Что | Реальная ОС ДИСПАК | dispak, HEAD `87f317b` |

гостевом коде.

NASA-коды `06502/06514/06501/06504/06511/06512` в нашем стенде
помечаются как `[аналог NASA, БЕНСОН-501]` (`extra.c:33`, `:224`, `:234`,
`:314`, `:505-537`), это не протокол НИТИ.

## 9. Про дешифратор команд Бенсона

Дешифратора команд от Бенсона в ОС **нет**. В `benson.be` есть только
программный **кодер вывода**: `G10236` (`:275-282`) раскладывает 48-битное
слово на 16-разрядные элементы, `G10161/G10175` (`:180-228`) упаковывают их
в кольцевой буфер `ячсост` по адресам `0330..0377`, откуда байты уходят через
